# 작성 범위와 AI 활용 고지

이 문서는 프로젝트별 저작·기여 범위와 생성형 AI 활용 방식을 명확히 하기 위한 것입니다. AI가 제안하거나 생성한 내용도 제출자가 직접 코드와 실행 결과를 검토하고 설명할 수 있는 범위만 저장소에 포함합니다.

## Dophamine Addiction

- 4인 졸업작품입니다.
- 이태현은 WinSock2/IOCP 로그인·로비 서버, Lobby와 Unreal Dedicated Server 연결, 서버 lifecycle과 재접속, 서버 권위 상태·판정, 서버 권위 충돌·획득과 카드 배치 판정 일부를 담당했습니다.
- 공개 묶음에는 위 역할을 검토하는 데 필요한 코드와 본인 개발 기록만 선별합니다. 클라이언트 UI·아트·외부 에셋과 팀원의 독립 구현물은 제외합니다.
- 팀 저장소에서 공동 통합된 파일은 파일 전체를 단독 구현했다고 표현하지 않고, README에서 담당 함수와 통합 경계를 설명합니다.
- 후기 개발 과정에서는 생성형 AI를 코드 검토, 문제 원인 분석, 수정 후보와 검증 항목 정리에 활용했습니다. 적용 여부 판단, 원본 프로젝트 반영, 빌드와 실제 플레이 확인은 이태현이 수행했습니다.

## C++ IOCP 2D MMORPG

- 개인 학기 프로젝트입니다.
- 서버 네트워크, 세션과 송신 수명, world/DB worker, 게임 로직과 클라이언트를 직접 구현한 범위를 중심으로 공개합니다.
- 수업에서 제공됐거나 제공 가능성이 있는 protocol header와 sample 기반 StressTest 코드는 공개 묶음에서 제외하거나 출처를 별도로 표시합니다.

## EverPlanet World Study

- 개인 기술 연구 프로젝트입니다.
- 어릴 때 즐겨 한 Nexon 게임 `EverPlanet`을 개발 연습의 출발점으로 삼아, “이 공간과 카메라를 기술적으로 어떻게 구현했을까”를 질문하며 분석·구현하고 있습니다.
- Unreal Engine C++로 구면 중력·접선 이동·local-Up 카메라를 연구한 뒤, 현재 신규 구현은 Godot의 작은 playable slice로 전환했습니다.
- 생성형 AI를 설계 대안 조사, 코드 초안, 테스트 항목 도출, 문서와 시각 반복 작업 정리에 활용했습니다.
- 구현 방향 결정, 원본 프로젝트 적용, 빌드·PIE 실행, 실패 분석과 수용 여부 판단은 이태현이 수행했습니다.
- 원작의 소스·데이터·그래픽·음원은 사용하지 않습니다.

## Football Owner

- Football Manager에서 영감을 받아 구단주 관점으로 재해석한 개인 기획·구현 프로젝트입니다.
- 이태현이 제품 방향, 요구사항, 도메인 규칙, 검증 기준과 최종 통합을 담당했습니다.
- 생성형 AI를 코드 작성과 리팩터링, 테스트·데이터 검증 도구 제작에 폭넓게 활용했습니다. 따라서 README에서는 “AI 보조 개인 개발”로 명시하고, 전부를 수작업 단독 구현으로 표현하지 않습니다.
- 저장소에는 직접 설명하고 검증할 수 있는 코드만 포함하며, 실존 선수·구단의 대규모 데이터와 source-game 기반 ratings 자료는 제외합니다. 코드 안의 소규모 1992-93 prototype fixture는 공개 역사 자료와 자체 gameplay estimate를 구분해 출처를 기록합니다.

## 계약과 공명 RPG

- 현재는 GDD와 기술 구조를 설계한 기획 프로젝트이며, 구현 완료 프로젝트로 주장하지 않습니다.
- 생성형 AI를 아이디어 정리, 문서 구조화와 검토에 활용했고, 게임의 방향·규칙 선택과 최종 편집은 이태현이 수행했습니다.
