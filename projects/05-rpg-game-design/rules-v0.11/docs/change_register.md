# v0.10 → v0.11 변경 기록

2026-09-11. 출처: 사용자 제공 v0.10과 직전 검토. 아래 수정값은 사용자 위임에 따라 새로 정한 프로토타입 기준이며 원문에 이미 있던 내용으로 주장하지 않습니다.

## 유지

세계와 공명 산업의 주제, 주인공의 공식 사망/실제 현장 유기, 억제 장비 생존 의존, 보호자의 뒤늦은 발견, 공명 재구축, 장비 교체 시 프롤로그 종료, 6명 필수 인원/최대8명 전후열, 두 무기 약점과 캐릭터·계약체 역할 분리를 유지합니다. 전체 캠페인 설정을 데모의 편의를 위해 바꾸지 않습니다.

## 완료와 검증 상태

63개 지정 검사 및 별도 흔적 Golden fixture, Lua5.4 대조는 실행 완료입니다. 8경로 잔고 계산은 63개 중 일부입니다. 정적 UI는 렌더·시각 확인했지만 브라우저/패드/SFML 입력은 미검증입니다. 전체 전투 경기 수·승률·보스 난이도·강화 효율·실제 탐험 시간은 보고하지 않습니다.

다음 실제 작업은 이 입력을 C++ BattleController/EffectResolver에 이식하고 같은 단위 결과를 대조하는 것입니다. C++ 이식 완료와 게임성 검증 완료는 별도입니다.
