# AI 보조 범위

## 이태현이 담당한 것

- 좋아했던 게임의 공간 경험을 기술 문제로 다시 정의
- engine 전환, first slice 범위와 우선순위 결정
- 요구사항, 완료 기준과 확인하지 않은 항목의 경계 설정
- Unreal/Godot project 적용과 local build/run
- capture 비교, bug 재현, 수정 수용 여부와 최종 판단

## AI를 활용한 것

- 구면 중력·camera frame 설계 대안 분석
- C++/GDScript/Python code 초안과 refactoring
- automation test와 verification checklist 생성
- worklog와 설계 문서 구조화
- visual pass의 scene/material 반복 제작 보조

## 제출 원칙

- AI가 제안한 설명만으로 완료를 주장하지 않습니다.
- 실제 source와 실행·test 근거가 있는 범위만 구현 내용으로 적습니다.
- 원작 구현을 확인한 것처럼 표현하지 않고, 관찰을 바탕으로 독립적으로 설계한 연구임을 명시합니다.
