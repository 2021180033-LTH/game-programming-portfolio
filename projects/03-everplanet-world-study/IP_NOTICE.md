# IP 및 asset 고지

- `EverPlanet`과 관련 상표·원작 저작물은 Nexon과 각 권리자에게 있습니다.
- 이 프로젝트는 비공식 개인 개발 연습·기술 연구이며 Nexon과 제휴·승인 관계가 없습니다.
- 원작의 source code, data, model, texture, UI와 audio를 포함하지 않습니다.
- 원작 영상에서 추출한 reference frame은 분석에만 사용했고 공개 묶음에서 제외했습니다.
- Unreal `Content`, engine template/Marketplace asset과 재배포 권한이 불명확한 자료를 제외했습니다.
- Godot 공개 폴더에는 project source, scene/material/shader와 자체 진행 capture만 선별했습니다.
- `unreal-study` source 첫 줄의 Epic copyright 문구는 Unreal template이 생성한 boilerplate header를 원형 보존한 것입니다. 그 아래 사용자 구현의 기능·검증 범위는 README에서 별도로 설명합니다.
