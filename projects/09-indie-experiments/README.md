# 개인 창작 게임의 규칙과 작업물

이 컬렉션에는 전투의 다음 행동, 선수 사이의 연결, 등장인물의 기억을 서로 다른 규칙으로 다룬 게임 세 편을 담았습니다. 각 항목에서 기획서의 해당 부분과 프로젝트에서 확인한 구현 범위를 읽을 수 있습니다.

| 프로젝트 | 다룬 질문 | 작업물 |
| --- | --- | --- |
| 종이 삼킨 새벽 · v0.4.0 | 네 동료가 같은 약점을 계속 공격할 때와 서로 다른 약점을 번갈아 공격할 때 어떤 차이가 생길까? | [공유 자원과 전투 판정](paper-dawn.md) |
| Teammate Chain · V1 연결 규칙 | 어느 두 선수가 같은 팀에서 뛰었다는 것을 게임은 무엇으로 판정할까? | [동료 연결 판정과 회귀 시험](teammate-chain.md) |
| 이어지는 이야기 · 기획 v0.7 / Android 시험판 v0.4.0 | 인물이 잊어버린 일을 플레이어의 세계 기록에서는 어떻게 남길까? | [기억·분기 규칙과 시험판의 적용 범위](roleplay.md) |

『이어지는 이야기』의 기록 보존과 망각 조건은 기획서에 제작자 확정 요구로 남아 있습니다. 나머지 두 편은 프로젝트의 디자인 노트, 규칙, 소스에서 확인한 작업을 실었습니다. 개별 문장, 코드 및 아트별 제작자와 AI 분담은 특정하지 않았습니다.
