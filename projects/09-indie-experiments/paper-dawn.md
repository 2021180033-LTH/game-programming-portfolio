# 종이 삼킨 새벽

하람 마을에서 사람들이 이름과 기억을 잃기 시작합니다. 네 여행자는 하람과 메아리숲, 별무덤 유적을 거치며 마을이 재해를 막기 위해 무엇을 대가로 치렀는지 밝힙니다. v0.4.0의 3막 이야기와 두 결말은 공동체를 지키는 방법을 플레이어가 선택하도록 구성합니다.

## 네 명이 번갈아 약점을 칠 이유

디자인 노트의 ‘균열과 겹빛’ 원문입니다.

> 전투는 무작위 명중 실패보다 읽을 수 있는 계획을 우선합니다. 약점 피해는 1.3배이며 균열치를 쌓습니다. 같은 약점 반복은 균열치가 62%로 감소하지만 다른 약점으로 이어 맞히면 +15가 추가됩니다.
>
> 겹빛은 0~6의 파티 공유 자원입니다. 교차 균열과 적 균열에서 획득하고 라운드 종료 때 하나가 추가됩니다. 한 라운드에는 겹빛 기술을 하나만 사용할 수 있습니다.

표준 난이도에서 기본 균열치가 20인 기술을 쓸 때, 직전에 친 약점을 다시 치면 반올림 결과가 12입니다. 다른 약점 속성으로 이어 치면 35가 됩니다. 다룰 수 있는 속성이 다른 동료를 번갈아 행동시키는 이유입니다. 겹빛을 3 이상 남겨 받는 피해를 8% 줄이거나, 2~3을 써서 합동기를 사용할 수 있습니다.

## 실제 전투 판정 발췌

`game/combat.ts`의 약점 판정입니다. 마지막 줄에서 이야기 난이도의 보정을 적용합니다.

```ts
  let fracture = weakness ? skill.fracture ?? 20 : 0;
  if (weakness && enemy.lastWeakness && enemy.lastWeakness !== element) {
    fracture += 15;
  } else if (weakness && enemy.lastWeakness === element) {
    fracture = Math.round(fracture * 0.62);
  }
  if (difficulty === 'story') fracture = Math.round(fracture * 1.16);
```

교차 공격과 반복 공격의 결과를 비교하는 회귀 시험도 프로젝트의 `tests/combat.test.ts`에 있습니다. 이 발췌는 게임 v0.4.0의 `docs/game-design.md`와 소스를 기준으로 정리했습니다.
