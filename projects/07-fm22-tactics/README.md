# Football Manager 2022 전술·선수 능력치 실험

측면에서 골라인 근처까지 전진한 뒤 뒤로 공을 내주는 컷백 전술에서 어떤 선수를 먼저 영입해야 할지 알아보기 위한 수업 실험입니다. 제가 전술을 고정하고 선수 능력치를 편집한 뒤 경기 결과를 비교했습니다.

| 실험 조건 | 관찰한 경기 결과 |
|---|---|
| 신체 20, 기술·정신 5 | 첫 시즌 34승 4무로 우승. 두 번째 시즌 32승 4무 2패 |
| 신체 5, 기술·정신 20 | 11경기 1무 10패, 69실점 후 감독 경질 |

높은 수비 라인과 압박을 유지하는 이 전술에서는 패스 능력만으로 상대를 앞지를 수 없었습니다. 다음 영입 후보를 볼 때는 측면에서 침투하고 수비로 복귀할 주력·가속력을 먼저 보기로 했습니다. 여러 능력치를 같이 바꿨고 비교 팀은 11경기에서 끝났으므로 개별 수치의 효과나 다른 전술의 성능까지 이 결과로 판단할 수는 없습니다.
