# PC 던전앤파이터 115레벨 무기고 역기획

**[제출용 PDF · 10쪽](armory-design-review.pdf)** · [Word 편집본 다운로드](armory-design-review.docx?raw=true)

최후의 조율자를 몇 주간 돌면서 같은 세트를 여러 캐릭터에 맞추는 과정을 분석했습니다. 처음 세트를 모을 때에는 새 부위가 착용 선택과 세트 효과를 바꿉니다. 같은 세트를 다시 맞추는 부캐에서는 이미 아는 조합을 사용하기까지 같은 드롭을 한 번 더 기다리게 됩니다.

본캐와 부캐 둘이 같은 상의를 입고 싶은 경우를 기준으로 드롭률 인상, 초월 비용 인하, 무기고 등록 품목 공유를 비교했습니다. 초월 비용이 0이어도 상의 한 벌을 세 캐릭터가 동시에 입을 수는 없습니다. **등록한 품목을 계정에서 공유**하면 부캐가 이미 모은 부위를 다시 기다리는 부담을 줄이고, 각 캐릭터가 투자한 강화·증폭도 보존할 수 있습니다.

제안이 다른 수집과 거래에 미치는 영향도 다뤘습니다. 빛의 서약 중복 보정, 초월 재료 수요, 레이드 카드 공급은 서로 다른 원인으로 변합니다. 가상 100계정 사례에서는 개인 드롭 한도가 어느 상황에서 공급 증가분보다 많은 카드를 줄이는지 비교했습니다.

| 쪽 | 내용 |
|---|---|
| 1–2 | 처음 세트를 모을 때와 같은 부위를 다시 구할 때의 차이, 세 가지 대안 중 등록 품목 공유를 선택한 이유 |
| 3–4 | 무기고 등록 품목의 계정 공유, 남레인저의 무기 변환 사례와 승급 장비 등록 기준 |
| 5 | 빛의 서약 중복 보정, 계정에 태초 서약 11종을 등록했을 때 마지막 한 종의 획득 변화 |
| 6–7 | 목표 세트 착용에 걸린 일수와 파밍 피로도 측정, 상위 콘텐츠의 개인 보상과 공격대 경매 공급 비교 |
| 8–9 | 가상 100계정의 카드 한도 비교, 한도 도달 후 보상, 하드 최초 클리어 칭호 및 한도 완화 기준 |
| 10 | 부록. 최후의 조율자·심연·랜턴그리드·제작기·초월의 비용과 계산 근거 |

2026년 11월의 게임 규칙과 플레이 경험을 바탕으로 작성한 개인 기획 과제입니다. 게임에 도입된 변경 사항과 구분해 문서 안에 제안으로 표시했습니다.
