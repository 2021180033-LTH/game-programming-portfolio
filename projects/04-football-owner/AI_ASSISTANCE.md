# AI 보조 범위

Football Owner는 1인 개인 프로젝트이며 생성형 AI/Codex를 적극적으로 활용했습니다.

## 이태현이 담당한 것

- Football Manager 기반 구단주 관점이라는 제품 방향
- 기능 요구사항, 우선순위와 수용 기준
- 시대 규칙과 domain model에서 사용할 가정의 선택
- 실행 결과 검토, bug 재현, 수정 수용 여부와 최종 판단
- 기획과 구현의 통합, 공개 범위와 권리 판단

## AI를 활용한 것

- C++/Qt/QML/SQLite 코드 초안과 반복 구현
- refactoring 대안과 migration 구조 제안
- regression test와 data validation 도구 작성
- 문서화, 상태 정리와 누락 항목 점검

## 제출 원칙

- AI가 생성한 코드를 모두 수작업 단독 구현으로 표현하지 않습니다.
- 본인이 코드의 목적·상태 변화·검증 결과를 설명할 수 있는 범위만 포함합니다.
- 실제 build/test 결과와 source를 우선하고, AI의 판단만으로 기능 완료를 주장하지 않습니다.
