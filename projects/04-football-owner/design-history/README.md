# Football Owner 통합 기획서 개정 이력

**Football Owner**는 과거의 축구 구단을 인수해 선수단을 구성하고, 여러 시즌에 걸쳐 내 구단의 역사를 만드는 싱글플레이 경영 시뮬레이션입니다. 처음 읽는 분에게는 기획 동기를 적은 [2차 기획서 4쪽](versions/v02-player-motivation.pdf#page=4)과 구단주가 직접 결정하는 일을 정리한 [8차 기획서 35쪽](versions/v08-career-and-era-rules.pdf#page=35)을 추천합니다.

## 왜 구단주 게임을 만들었나

Football Manager를 할 때 가장 재미있었던 건 좋아하는 선수를 데려와 주전으로 키우는 일이었습니다. 전술을 직접 짜는 데는 자신이 없어서, 애써 꾸린 팀에서 경질될까 걱정되면 다른 유저가 만든 전술을 내려받아 쓰기도 했습니다. 정작 구단에 돈이 있어 훈련 시설을 개선하고 싶을 때는 좋은 성적을 거둔 뒤에도 이사회에서 요청이 여러 번 거절됐습니다.

예전 시즌의 선수단을 불러오고 이후 데뷔하는 실존 선수들까지 만나려면 비공식 데이터와 모드도 따로 찾아야 했습니다. 저는 기억에 남는 선수들을 모아 무너진 구단을 재건하거나, 이미 강했던 팀으로 실제보다 큰 업적을 남기고 싶었습니다. 그래서 경기 지휘는 감독에게 맡기고, 어떤 선수를 영입해 키울지, 구단 예산을 어느 시설에 먼저 쓸지는 제가 결정하는 게임을 기획했습니다.

## 기획과 개발본의 범위

0.24 개발본에서는 구단 인수와 취임 약속, 직원 채용 위임, 선수 관찰·영입·계약, 재정 정산을 거쳐 다음 시즌 첫 경기까지 진행할 수 있습니다. 예를 들어 감독 유임을 약속한 뒤 실제로 감독을 해임하면 약속을 어긴 것으로 기록합니다. 직원 채용은 감독이 인력을 요청하고, 구단주가 미리 승인한 급여 한도 안에서 단장이 처리할 수 있습니다.

실존 미래 선수의 시대별 등장, 시설 건설과 스폰서 협상, 팬 집단별 반응, 은퇴 선수의 지도자 전환, 대표권 상실 뒤 재인수는 후속 개발 범위입니다. 제가 게임 방향과 시스템 규칙을 정하고 개발 우선순위·검증 기준·최종 통합을 맡았습니다. 구현 과정에서 코드 작성, 리팩터링과 자동 검증에 AI를 활용했습니다.
