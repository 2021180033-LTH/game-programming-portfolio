# 한 판 진행 예시와 첫 플레이테스트 항목

아래는 [종이판 규칙](paper-rules.md)을 읽은 두 사람이 같은 결과를 얻을 수 있는지 확인하는 예시다. 지정한 주사위 눈으로 계산했으며 실제 참가자의 행동 기록은 아니다.

## 9일 동안 한 선택

‘관찰자’는 **모든 것을 관찰하는**, ‘숨긴 이’는 **신앙을 숨긴**의 줄임말이다. 시작 잔액은 자금 4, 정보 1, 지식 1이다. 표의 수치는 그날의 밤 행동과 날짜 정산을 모두 마친 뒤의 값이다.

| 일차 | 낮 | 밤과 주사위 | 자금 / 정보 / 지식 | 소문 |
| ---: | --- | --- | --- | ---: |
| 1 | 일한다. | 숨긴 이 혼자 자금 2로 동굴 탐색. 눈 4, 기준 4로 발견. | 4 / 0 / 1 | 0 |
| 2 | 공부한다. | 관찰자가 지식 1로 동굴을 정화. 관찰자의 동굴 불이익은 위치를 찾을 때만 적용된다. | 4 / 1 / 1 | 0 |
| 3 | 일한다. | 둘이 자금 3으로 거미줄 탐색. 눈 5, 기준 6으로 발견. 관찰자는 스트레스 30과 동행 카드 1장을 받는다. | 3 / 0 / 1 | 0 |
| 4 | 공부한다. | 숨긴 이가 자금 1로 장비를 옮겨 통로를 제거. | 2 / 1 / 2 | 0 |
| 5 | 일한다. | 관찰자 혼자 자금 2로 서고 탐색. 장소 특성을 더한 기준이 5라서 눈 5로 발견. 누적 스트레스 60이 카드로 바뀌어 관찰자는 총 2장, 잔여 수치 0이 된다. | 2 / 0 / 2 | 0 |
| 6 | 공부한다. | 쉬어야 하는 관찰자 대신 숨긴 이가 지식 1로 서고에서 마도서를 가져온다. 여섯째 밤이 지나 소문 +1. | 2 / 1 / 2 | 1 |
| 7 | 지식 2로 마도서를 해독한다. | 숨긴 이가 자금 2로 르뤼에 탐색. 눈 8, 기준 4로 실패. 들고 간 마지막 자금과 정보가 소모된다. | 0 / 0 / 0 | 1 |
| 8 | 공개 수소문으로 자금 2와 정보 1을 함께 얻는다. | 숨긴 이가 자금 2로 재탐색. 눈 3, 기준 4로 발견. 수소문으로 오른 소문 1은 남는다. | 0 / 0 / 0 | 2 |
| 9 | 공부한다. | 숨긴 이와 마도서를 보내 의식을 치른다. **연구가 발각된 적이 없어 크툴루가 부활한다.** | 0 / 1 / 1 | 2 |

3일차에 자금을 2만 쓰면 두 명을 보내도 성공 기준은 5다. 5까지 나온 이번 예시에서는 돈을 더 들이지 않아도 성공했겠지만, 보낼 때는 주사위 눈을 모른다. 7일차에 자금과 정보가 모두 떨어진 뒤에는 공개 수소문이 하루를 아낀다. 조용히 일하면 그날은 정보가 없어 쉬고 다음 낮에 공부한 뒤 다시 시도해야 한다.

## 판정이 달라지는 상황

| 확인할 조건 | 입력과 기대 결과 |
| --- | --- |
| 최저 투자와 장소 보정 | 관찰자 혼자 자금 2로 동굴을 찾으면 기준은 3이다. 눈 4는 실패다. 같은 인물·비용으로 서고를 찾으면 기준 5라서 눈 4는 성공이다. |
| 파티 상한과 자동 성공 | 네 명·자금 4에 유리한 보정까지 있어도 기준은 9다. 눈 10으로 두 번 연속 실패했다면 같은 곳에 세 번째 출발할 때는 성공한다. 세 번 모두 정보·자금·스트레스·소문이 각 1회씩 정산된다. |
| 인원에 따른 소문 | 두 명과 세 명으로 같은 장소를 찾는다. 돈과 특성이 같으면 세 명일 때 성공 눈금이 1 높아지며, 세 명을 보낸 쪽만 소문 +1이다. |
| 치료 시점 | 카드 1장·잔여 스트레스 30인 일반 동료를 혼자 탐색에 보내면 카드 2장·잔여 0으로 귀환한다. 다음 밤에는 치료로 지식 1을 쓰고 카드 1장을 제거해야 그다음 밤부터 다시 나간다. |
| 연구 발각의 지속 | 소문 5에서 공개 수소문을 하면 즉시 발각된다. 완료한 던전에 흔적 정리를 써서 5로 되돌린 뒤 의식을 치러도 윌버는 경비견에게 쫓겨 죽는다. |
| 최종 밤의 정산 순서 | 소문 5, 미발각, 르뤼에 발견 상태에서 여섯째 또는 열두째 밤에 의식을 치르면 부활 결말이다. 의식을 미루고 쉬면 그날 정산에서 6에 닿아 발각된다. |
| 재발급·중복 보상 | 완료한 서고에 다시 파견하거나, 부활 방법을 이미 가진 상태에서 마도서를 다시 해독하려 하면 비용과 시간이 차감되지 않는다. |
| 자원이 바닥난 판 | 자금·정보·지식이 모두 0인 날에도 일 또는 공부를 할 수 있다. 스트레스에 면역인 시작 동료를 혼자 보내는 길이 남으므로 일반 동료가 모두 쉬는 상태에서도 진행 가능하다. |

## 실제 테스트에서 보고 싶은 점

- **첫 탐색을 정하기 전** 참가자에게 ‘한 명·자금 2’와 ‘두 명·자금 3’의 대가를 말해 달라고 한다. 40%와 60%만 말하고 동행 카드나 소문 조건을 놓친다면, 확정 전에 변경될 자원과 인물 상태를 같은 칸에 표시한다.
- **첫 실패 직후** 사라진 자원과 남은 단서를 직접 적게 한다. 발견에 성공해야만 스트레스를 받는다고 이해하거나, 이미 찾은 장소를 또 탐색하면 ‘발견’과 ‘공략’ 표시를 손본다.
- **한 판을 마치고** 어느 날 시간과 비밀 중 무엇을 더 중요하게 봤는지 묻는다. 모두가 면역 동료 한 명만 보내고 소문을 고려할 일이 없었다면 소문 증가 주기와 인원별 성공률을 각각 바꿔 비교한다. 두 값을 동시에 바꾸면 어떤 변경이 선택에 영향을 주었는지 알기 어렵다.
- 기록지에는 날짜, 고른 행동과 이유, 확정 전 예상 결과, 실제 결과, 종료 때 처음 알게 된 규칙을 적는다. 플레이 인원수·승률·소요 시간은 실제 세션 뒤에 기록한다.
