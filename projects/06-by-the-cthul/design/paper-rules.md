# 종이 프로토타입 규칙

윌버의 목표는 동굴·거미줄·서고의 조사를 끝내고, 크툴루가 잠든 르뤼에를 찾아 부활 의식을 치르는 것입니다. 사람을 많이 동원하면 빨리 찾을 수 있지만 소문이 납니다. 의식에 도달했을 때 연구가 이미 발각됐다면 윌버가 죽고, 비밀을 지켰다면 크툴루가 깨어납니다.

## 원안에서 이어받은 규칙

| 2021년 기말 제안서 | 종이판에서 정한 내용 |
| --- | --- |
| 낮에 일·공부·포섭을 하고 밤에 던전을 탐색한다. 32~36쪽 | 여러 행동 칸이 열렸을 때도 낮 1회, 밤 1회만 선택한다. 첫 안내 장면은 본 뒤의 상태에서 시작한다. |
| 정보 1장, 인물 1~4명, 자금 2~4개로 탐색한다. 성패와 무관하게 스트레스 30을 얻는다. 35쪽 | 주사위 눈으로 성공을 판단하고 스트레스의 소유자, 카드 전환, 실패 보정을 정한다. |
| 신앙을 숨긴 협력자는 스트레스 카드 면역이며 다른 인물과 함께 행동하면 카드 1장을 추가로 만든다. 15쪽 | 동행한 일반 협력자 한 명이 추가 카드를 받는다. 해당 협력자가 혼자 나가면 추가 카드가 생기지 않는다. |
| 세 던전을 공략하고 마도서를 연구해 르뤼에를 연다. 연구 발각 여부로 결말이 갈린다. 9·27~31·42~43쪽 | 첫 시험에서는 던전마다 고유 목표 하나만 판정한다. 비밀이 드러나는 기준을 소문 수치로 공개한다. |

아래 수치와 행동 횟수는 2026년 보완안의 시험값이다. 수업 원안의 협력자 아홉 명 중 네 명으로 한 판을 구성한다.

## 한 판 준비

종이 한 장, 연필, 10면 주사위 하나를 준비한다. 0~9가 적힌 주사위의 0은 10으로 읽는다. 지도에 **니오그타의 동굴 → 아틀락 나챠의 거미줄 → 니알라토텝의 서고 → 르뤼에**를 적고 각 장소에 발견·완료 칸을 그린다. 자금 4, 정보 1, 지식 1, 소문 0에서 시작한다.

윌버는 낮 행동과 밤 행동을 지휘한다. 파티 인원수는 파견하는 협력자만 센다. 시작 동료는 ‘모든 것을 관찰하는’과 ‘신앙을 숨긴’이다. ‘강건한’, ‘신의 도서를 읽은’은 포섭으로 데려온다. 이름 뒤의 효과는 이 종이판에 적용하는 규칙이다.

| 협력자 | 행동을 고르게 만드는 차이 |
| --- | --- |
| 모든 것을 관찰하는 | 서고를 찾는 탐색에 참여하면 성공 눈금 +1, 동굴을 찾을 때는 −1. |
| 신앙을 숨긴 | 스트레스 수치와 카드를 받지 않는다. 두 명 이상이 함께 탐색하면 동행 중 한 명을 골라 스트레스 카드 1장을 더 준다. |
| 강건한 | 거미줄 공략 때 참여하면 장비 운반비 1을 절약한다. 탐색 인원으로는 한 명이다. |
| 신의 도서를 읽은 | 서고 완료 후 마도서를 해독할 때 활동 가능한 상태라면 지식 비용이 2에서 1로 내려간다. |

## 하루의 진행

날짜를 1일부터 센다. 하루는 **낮 행동 하나 → 밤 행동 하나 → 날짜 정산** 순서다. 행동 확정 전에 비용, 성공 눈금, 예상 소문 증가량을 적는다. 비용을 감당할 수 없거나 이미 완료한 장소를 고르면 같은 시간대에서 다시 선택한다. 자원은 행동을 확정할 때 한 번 차감한다.

| 낮 행동 | 판정 |
| --- | --- |
| 일 | 자금 +2. |
| 공부 | 정보 +1, 지식 +1. |
| 공개 수소문 | 사람들에게 대놓고 묻는다. 자금 +2, 정보 +1을 얻고 소문 +1. 조용히 일하는 것보다 정보를 빨리 모을 수 있다. |
| 포섭 | 자금 1과 정보 1을 써서 대기 중인 두 협력자 중 한 명을 데려온다. 그날 밤부터 파견할 수 있다. |
| 마도서 해독 | 세 던전 완료 후 네크로노미콘과 지식 2가 필요하다. 지식만 소비하고 **부활 방법**을 얻는다. 1회만 가능하다. |
| 흔적 정리 | 완료한 일반 던전 하나를 골라 지식 1을 쓰고 소문을 1 낮춘다. 각 던전당 1회이며, 소문이 0이면 사용할 수 없다. 발각 기록은 지워지지 않는다. |

| 밤 행동 | 판정 |
| --- | --- |
| 탐색 | 현재 장소를 아직 발견하지 못했다면 시도한다. 아래 공식으로 위치를 발견하는지 판단한다. |
| 공략 또는 의식 | 발견한 장소의 고유 조건을 충족하면 완료한다. 활동 가능한 협력자 1명을 고른다. 추가 주사위는 굴리지 않는다. |
| 치료 | 지식 1을 써서 동료 한 명의 스트레스 카드 1장을 없앤다. 윌버가 치료하므로 쉬고 있는 동료도 고를 수 있다. |
| 휴식 | 비용과 효과 없이 밤을 마친다. 살림을 다시 갖출 때 쓸 수 있고 날짜는 정상적으로 흐른다. |

## 밤에 장소 찾기

1. 정보 1, 자금 2~4, 활동 가능한 동료 1~4명을 낸다. 자금과 정보는 성공 여부와 관계없이 소비된다. 협력자는 파견 뒤 돌아온다.
2. 성공 눈금은 **4 + (동료 수 − 1) + (자금 − 2) + 장소별 특성 보정**이다. 최종 눈금은 1~9로 제한한다. 주사위가 눈금 이하면 발견 칸에 표시한다. 보정 없는 경우 한 명·자금 2는 40%, 두 명·자금 3은 60%, 네 명·자금 4는 90%다.
3. 같은 장소에서 두 번 연속 실패하면 확보한 단서로 세 번째 탐색이 자동 성공한다. 세 번째에도 자금·정보를 쓰고 스트레스·소문을 적용한다. 중간에 공부하거나 쉬어도 실패 기록은 남는다. 다음 장소의 실패 기록은 0부터 센다.
4. 파견한 일반 동료 각각의 스트레스에 30을 더한다. 누적 60마다 수치에서 60을 빼고 그 동료에게 카드 한 장을 준다. ‘신앙을 숨긴’이 동행했다면 일반 동료 한 명을 골라 추가 카드 1장을 준다. 카드가 2장 이상인 동료는 다음 파견·공략에 나갈 수 없다. 치료로 한 장 이하가 되면 다시 활동한다. 카드 수와 남은 수치는 따로 적는다.
5. 세 명 이상을 한 번에 보냈으면 소문 +1. 성공·실패 양쪽에 적용한다. 공략은 이미 찾은 장소에 한 사람을 보내므로 탐색의 스트레스와 소문을 적용하지 않는다.

소문은 0 밑으로 내려가지 않는다. 6일, 12일, 18일처럼 6의 배수인 날의 밤을 마칠 때 소문이 1 오른다. 행동이나 날짜 정산으로 소문이 **처음 6에 닿는 순간** ‘연구 발각’에 표시한다. 나중에 수치를 내리더라도 시민들이 알았던 사실은 남는다. 최종 의식은 그 밤의 날짜 정산 전에 결말을 결정한다.

## 던전별 진행과 결말

| 장소 | 탐색이 열리는 조건 | 발견한 다음 밤에 할 일과 결과 |
| --- | --- | --- |
| 니오그타의 동굴 | 처음부터 탐색 가능 | 지식 1을 써서 앙크·주문·영액에 관한 단서를 맞추고 흔적을 정화한다. 동굴 완료. |
| 아틀락 나챠의 거미줄 | 동굴 완료 | 장비 운반비 1을 내고 통로를 끊는다. ‘강건한’을 보내면 비용 0. 거미줄 완료. |
| 니알라토텝의 서고 | 거미줄 완료 | 지식 1을 쓰고 부등다면체와 네크로노미콘을 확보한다. 서고 완료. 다음 낮부터 마도서 해독 가능. |
| 르뤼에 | 세 던전 완료 및 부활 방법 보유 | 발견한 뒤, 활동 가능한 동료 한 명과 마도서를 내고 의식을 치른다. **발각**이면 경비견에게 쫓긴 윌버의 죽음, **미발각**이면 크툴루의 부활과 인류 멸망으로 끝난다. |

한 번에 현재 장소 하나만 열린다. 발견한 던전은 다음 밤부터 공략할 수 있다. 완료 표시가 있는 던전에서 유물을 반복 획득할 수 없다. 원안의 여러 구간과 보스 묘사는 첫 종이판에서 한 번의 준비·공략으로 줄였다. 자금이나 정보가 바닥났을 때도 낮의 일·공부는 할 수 있다. 실패한 탐색 뒤 재정비할 여지를 남기되, 지연이 길어지면 소문이 커진다.
