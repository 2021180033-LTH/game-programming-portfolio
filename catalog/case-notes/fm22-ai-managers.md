# FM22 AI Managers Core · 감독 속성 패치의 반영 범위

감독의 경기 운영 성향에는 압박, 선수단 로테이션, 리드 시 수비처럼 서로 다른 선택이 들어 있다. 이 작업에서는 FM22에서 대응 관계를 확인한 인물과 속성만 에디터 데이터에 넣었다. 감독의 성향을 저장하는 데이터 작업으로, 경기 화면을 읽는 AIFM 도구와는 별개다.

## 입력에서 무엇을 골랐나

| 수정 기록 분류 | 행 수 |
| --- | ---: |
| 입력 기록 | 20,938 |
| 포메이션 또는 역할 체계에 해당해 제외 | 13,951 |
| 대상 인물이 없거나 선수로만 확인돼 제외 | 2,951 |
| FM22 에디터 데이터에 반영 | 4,036 |

변경 목록을 다시 집계하면 인물 216명, 속성 27종이다. 공격 성향, 압박, 선수단 로테이션은 각각 216명에게 기록됐고 수비 깊이(Depth)는 120명에게 기록됐다.

**검증 결과**　생성한 파일을 다시 읽어 확인하는 왕복 검사는 통과했다. 실제 FM22에서 새 커리어를 시작하는 시험과 경기를 돌려 전술 변화를 측정하는 시험은 당시 기록상 미검증이다. 따라서 4,036은 파일에 반영한 속성 수이며 감독 판단이나 경기 결과가 개선된 횟수는 아니다.

**작업 근거**　FM22_AI_Managers_Core의 changes.csv, validation.json. 인물 수와 속성 종류 수는 변경 목록의 서로 다른 인물·속성 키를 각각 집계했다.
