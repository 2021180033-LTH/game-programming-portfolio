# LongRP · 선택한 시작 장면과 세계별 기억

여러 이야기를 번갈아 플레이할 때 가장 먼저 지켜야 할 것은 이번에 고른 장면과 그 이야기의 설정이다. v1.8.10에서는 캐릭터 카드에 시작 장면이 여럿 있으면 플레이어가 하나를 선택하고, 본문을 첫 턴에 그대로 사용한다. 카드 설명과 시나리오를 읽어 장소·인물·초기 상태를 구성하는 절차는 별도로 진행한다.

## 같은 카드에서 두 세계를 만들 때

플레이어가 새 이야기를 열고 시작 장면, 주인공, 이 세계에서만 지킬 추가 지시를 입력한다. 카드의 설정집과 이미지도 해당 세계에 저장한다. 공통 설정은 여러 이야기에 적용할 수 있고, 특정 세계에 입력한 설정은 해당 이야기에서만 불러온다. 카드와 모듈에 설정집 항목이 겹치면 이름과 내용이 모두 일치하는 항목을 한 번만 등록한다.

당시 실제 카드로 확인한 설정집은 122개, 이미지 자료는 62개였다. 첫 턴에서 선택한 시작 장면이 유지됐고, 다음 턴에서 관련 키워드에 맞는 설정집 항목이 응답을 준비하는 데 쓰인 뒤 세계가 정상 저장됐다.

## 생성된 답변을 언제 저장하는가

| 검증기의 응답 | 턴 처리 |
| --- | --- |
| 승인, 오류 없음 | 저장 가능. 경고가 함께 있어도 통과 |
| 승인, 오류 있음 | 수정·재검증 |
| 거절, 경고만 있거나 사유가 비어 있음 | 수정·재검증. 허용 횟수 안에 통과하지 못하면 저장 중단 |

이전 처리에서는 거절된 답변에 경고만 붙으면 승인된 것으로 넘어갈 수 있었다. 판정값과 오류 유무를 함께 읽도록 바꿔, 이후 턴이 거절된 답변을 이미 벌어진 사건으로 이어 쓰는 문제를 막았다.

**작업 근거**　v1.8.10 변경 기록의 실제 카드 검증과 2026년 10월 21일 판정 수정. 사례에는 카드 본문과 이미지가 포함되지 않는다.
