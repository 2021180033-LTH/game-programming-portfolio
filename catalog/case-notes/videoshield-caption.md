# VideoShield / Caption Probe · 실행 검증과 효과 검증

두 실험은 영상 처리 후 무엇이 달라졌는지를 서로 다른 기준으로 본다. VideoShield의 최적화 기록에서는 같은 입력의 출력이 이전 처리와 일치하는지 확인했다. 별도로 만든 Caption Probe는 원본과 처리본의 이미지 설명을 비교할 방법을 마련했다.

## 최적화 전후에 실제로 비교한 값

VideoShield의 CPU 회귀 검사에서는 무작위 대조 경로의 출력 MP4, 미리보기, 프레임 단위 결과와 화질 지표(PSNR)가 이전 버전과 일치했다. 스트림 읽기 비교에서는 원본 프레임 24개와 처리 프레임 24개가 각각 바이트 단위로 일치했다. 취소 요청과 잘못된 입력도 별도 시험으로 처리했다. 이 결과는 최적화 과정에서 기준 출력이 바뀌었는지 확인한 것이다. 해당 보고서에서 GPU 동등성과 학습 방지 효과는 미검증으로 남았다.

## 캡션이 달라지면 무엇을 성공으로 볼 것인가

Caption Probe는 원본, 처리본, 무작위 대조군에 같은 설명 모델을 적용해 결과를 비교한다. 기록 양식은 문장 자체가 바뀌었는지와 **장면에 대해 새로 틀린 사실을 말했는지**를 별개로 다룬다. 예를 들어 ‘남자가 서 있다’가 ‘사람이 서 있다’로 바뀐 것만으로는 새 사실 오류가 생겼다고 볼 수 없다. 이 예시는 판정 기준을 설명하기 위한 것으로 실제 출력 문장이 아니다.

당시 실행 파일 빌드와 저장한 모델의 길이 1·2·7·14 출력 대조까지 확인했다. 계획했던 세 장면 전체 비교, MP4로 저장한 뒤의 재평가, 다른 모델에서도 같은 변화가 나타나는지에 대한 검증은 완료되지 않았다.

**작업 근거**　VideoShield 최적화 결과표(optimized_v1), C++ Caption Probe의 전달 시 검증 기록. 여기에 인용한 숫자는 실험의 작업 범위를 설명한다.
