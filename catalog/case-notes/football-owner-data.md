# FootballOwner_Data · 중단된 경기의 승점과 득실 처리

역사 시즌으로 구단을 운영하려면 경기별 기록을 합산한 결과가 당시 순위표와 일치해야 한다. 2025/26 내셔널리그 자료를 정리하면서 현장 점수와 공식 판정을 하나의 스코어로 표현할 수 없는 경기가 있었다.

## 2–1에서 끝난 경기의 기록

Scunthorpe United와 Wealdstone의 경기는 홈팀이 2–1로 앞선 상태에서 중단됐다. 프로젝트가 채택한 공식 판정은 홈팀에 승점 3점을 주고 양 팀의 득점과 실점은 순위표에 합산하지 않는 것이었다. 2–1 승리로 입력하면 승점은 맞아도 득실이 달라진다. 0–0으로 입력하면 무승부로 집계될 수 있다.

| 기록 대상 | 정정판에 저장된 값 |
| --- | --- |
| 경기 상태와 최종 스코어 | 행정 판정(AWARDED), 홈·원정 최종 스코어는 모두 비워 둠 |
| 중단 시점의 점수 | 홈 2, 원정 1 |
| 순위표 반영 | 승점은 홈 3, 원정 0. 득점 합산은 양 팀 모두 0 |

이 표는 2026년 9월 21일판 정정 DB에서 경기와 행정 결과를 경기 ID로 연결해 확인한 값이다. 정정판에는 경기 132,061행이 있고, 마지막으로 반영한 두 시즌의 출처 대조표에는 1,104행이 있다.

아래는 이 사례를 정정판에서 다시 확인할 때 사용한 조회문이다.

```sql
SELECT m.status, m.home_score, m.away_score,
       a.on_field_home, a.on_field_away,
       a.home_points, a.away_points,
       a.home_goals_counted, a.away_goals_counted
FROM build3_administrative_outcomes AS a
JOIN matches AS m USING (match_id);
```

## 7월 1일의 소속은 어떻게 판정했나

1993년 시작 선수단은 시즌 명단과 이적일이 충돌할 수 있다. 6월 1일과 14일로 이적일이 엇갈린 사례에서는 어느 기록을 택해도 7월 1일에 이전 구단 소속일 수 없다. 그 구단의 시작 명단에서는 제외하되 이적일의 두 후보를 보관했다. 반대로 출처에 7월 1일이라고만 적혀 있고 시즌 경계의 관행적 표기일 수 있으면 판정을 보류했다. 소속을 확정하기 위해 날짜까지 임의로 정할 필요는 없었다.
