# 윈도우 플랫폼 게임 · 스테이지 배치

2인 팀은 바운스볼의 점프 조작을 출발점으로 삼고, 투사체로 적을 상대하며 목적지에 도달하면 클리어하는 방식으로 제안했다. 계획서의 개인 분담은 배경·스테이지와 키 입력이다. 아래는 제출본의 배경 그리기 코드에서 확인한 스테이지 배치다.

| 지형 | 화면 좌표와 크기 | 배치 의도·형태 |
| --- | --- | --- |
| 세로 지형 2개 | (0, 0)에서 30×400, (250, 0)에서 30×100 | 세로로 긴 벽을 서로 다른 높이까지 그린다. |
| 가로 지형 2개 | (23, 395)와 (80, 100)에서 각각 400×30 | 화면 아래쪽과 위쪽에 긴 발판을 둔다. |
| 오른쪽 위로 오르는 계단 | 첫 칸 (420, 380), 30×30 타일 11개 | 다음 타일을 오른쪽 30픽셀, 위쪽 30픽셀에 둔다. |
| 오른쪽 아래로 내려가는 계단 | 첫 칸 (480, 100), 30×30 타일 3개 | 다음 타일을 오른쪽 30픽셀, 아래쪽 30픽셀에 둔다. |

제안서에서는 통과할 수 없는 장애물과 닿으면 체력을 잃는 장애물을 구분했다. 표의 좌표는 배경 코드에 실제로 들어간 값이다. 팀 계획서에 적힌 적·투사체·목적지 판정의 구현 여부까지 이 코드로 판단할 수는 없다.
