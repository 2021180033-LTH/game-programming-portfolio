# Tower Triumph · 카오스 던전

프로젝트 파일에는 **Tower Triumph**, 기말보고서의 게임 소개에는 **카오스 던전**이라는 제목을 사용했다. 아래는 기말보고서의 게임 진행과 팀원별 개발 내용을 옮겨 정리한 것이다.

### 마을에서 다음 던전까지

1. 마을 상점에서 전투에 가져갈 아이템을 구입한다.
2. 개방된 난이도와 던전 가운데 하나를 선택한다.
3. 격자 전장에서 속도에 따라 캐릭터의 차례가 돌아온다. 이동할 칸과 공격 방향을 선택한다.
4. 승리하면 경험치를 파티원에게 균등하게 나눠 주고 골드를 획득한다. 다음 던전에 도전하거나 마을로 돌아가 골드를 상점에서 사용한다.

### 담당한 작업

| 항목 | 기말보고서의 담당 기록 |
| --- | --- |
| 캐릭터 | 캐릭터 구현 |
| 상점 | 마을 상점 시스템 구현 |
| 스테이지 | 팀원과 스테이지 구현 분담 |

턴 진행과 UI는 다른 팀원이 맡았다. 이 두 요소는 캐릭터와 스테이지가 전체 게임 안에서 어떻게 쓰이는지 설명하기 위해 진행 순서에 포함했다.
