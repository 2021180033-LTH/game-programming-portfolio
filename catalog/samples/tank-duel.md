# Tank Duel 3D · 대전 규칙

두 사람이 같은 키보드를 쓰고 한 화면에서 탱크를 조종하는 게임이다. 제안서에서는 조준을 자동화해, 두 사람이 서로의 위치를 보며 이동·회피와 발사 시점을 결정하도록 했다. 아래 수치와 분담은 제안서 기준이다.

| 상황 | 규칙 |
| --- | --- |
| 경기 시작 | 두 탱크 모두 체력 100으로 시작한다. 처음 2초간 보호막을 적용한다. |
| 입력 | 1P는 WASD로 이동하고 Space로 발사한다. 2P는 방향키로 이동하고 Enter로 발사한다. |
| 발사와 피해 | 발사 간격은 0.8초다. 포탄 한 발이 명중하면 체력이 25 줄어든다. 보호막 종료 후 네 발을 맞으면 체력 100을 모두 잃는다. |
| 시간 종료 | 120초가 지나면 남은 체력이 많은 쪽이 승리한다. 체력이 같으면 무승부다. |
| 재시작 | F1로 대전을 다시 시작한다. |

개인 분담에는 전장과 공유 카메라, 자동 조준, 입력·이동·충돌, 발사·체력·시간 판정이 포함됐다. 통합 검증은 팀 작업으로 계획했다.
