# LM · 게임기획 1차 발표 발췌

수업에서 제안한 팀 운영 미니게임의 1차 발표 자료다. 4·8·9·11쪽에서 발표 문구를 발췌해 줄바꿈과 목록을 정리했다.

## 4쪽 · 게임 방법

- 훈련
- 유저가 정한 루틴, 내용 등을 토대로 선수들이 훈련을 진행
  - 체력, 능력치의 변화가 생김
  - 과도함, 부족함 영향 있음
- 경기 진행
- 플레이어는 경기에서 수행할 전략, 밴픽, 운영 등 여러 지점을 관여함
- 세트 당 선수 교체 역시 진행
- 피드백 진행
- 경기 전 중 후 선수 지정 혹은 선수 전체에게 전할 메시지 전달
- 그리고 경기 후에 칭찬 / 비난 가능
- 반복
- 그렇게 시즌이 끝날 때 까지 혹은 중간 휴식이 있을 때 까지 반복

## 8쪽 · 코어 루프 분석

영입 → 훈련/스크림 → 공식 경기 → 피드백 → 훈련

의사 결정 지점

1. 밴픽 전략 (메타/상대 챔프 풀/우리 커버리지)

2. 훈련 시간 배분 (개인 기량 vs 팀 시너지 vs 챔프 풀 확장)

3. 영입 / 계약 (즉시 전력 vs 잠재력, 샐러리 캡/연봉 총액 등)

4. 패치 대비 (예고된 패치에 따른 메타 예측)

## 9쪽 · 핵심 메커니즘 분석

- 밴픽 챔프풀 커버리지
- 목표 전략/상대 스카우팅 리포트 확인
- 챔프 풀 커버리지, 카운터 상성 테이블 확인
- 밴/픽 추천, 커버리지 점수(숙련도), 위험도 경고
- 시너지 보너스 or 상성 보정 제공
- 훈련 컨디션/시너지
- 훈련 메뉴 설정, 시간/코치 능력
- 컨디션, 피로, 개인 능력 or 시너지
- 주간 리포트, 시너지 레벨 증가, 부상/번아웃 위험도 증가
- 스크림/데이터 분석
- 상대 전투 풀/전술 가정, 내부/외부 스크림
- 전투 로그 제공, 전술 적합도 판정

## 11쪽 · 예상되는 문제점

패치 쇼크

패치 후 밴픽/전술이 통째로 무력화될 수 있음

패치 노트의 변화를 토대로 밴픽 추천 가중치

예산 격차

고연봉 스쿼드가 재미/도전을 압도

듀오/라인 시너지, 팀 컬쳐 보너스를 도입

결론 → 가중치를 통한 추천, 시너지를 통한 저연봉 혹은 유망주 사용 등을 가능하게 함
